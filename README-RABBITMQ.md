# RabbitMQ - Banco Cloud

## Descripción

Banco Cloud incorpora RabbitMQ para implementar comunicación asíncrona entre microservicios.

La solución utiliza:

- Producers
- Consumers
- Exchanges
- Queues
- Bindings
- ACK manual
- NACK
- Dead Letter Exchange
- Dead Letter Queue
- Microservicio administrador RabbitMQ
